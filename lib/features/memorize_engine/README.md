# features/memorize_engine

محرك الحفظ والتصحيح اللحظي: التسميع، إخفاء الآيات، العدّاد، التقاط الصوت، التعرف على التلاوة على الجهاز (On-Device AI)، ومحاذاة الكلمات وكشف أخطاء الحفظ والتجويد.

البنية الداخلية المعتمدة عند التنفيذ:

- `data/` الصوت والنماذج المحلية وقاعدة بيانات التقدّم.
- `domain/` الجلسة، المحاذاة، قواعد الأخطاء.
- `presentation/` شاشات الحفظ والتسميع.

المراحل المخططة: Step 3 إلى Step 6.
